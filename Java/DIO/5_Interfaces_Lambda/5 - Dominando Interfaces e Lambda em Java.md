Este repositório contém as minhas resoluções para os exercícios práticos propostos no curso de **Java** da plataforma [Digital Innovation One (DIO)](https://www.dio.me/). O objetivo aqui é documentar meu aprendizado e praticar os conceitos básicos de lógica de programação e sintaxe da linguagem.

## 📚 Os Exercícios

Abaixo está a lista dos exercícios propostos pela DIO que foram desenvolvidos neste repositório:

- [ ] **15. Sistema de Disparo de Mensagens (Marketing)**
  - **Objetivo:** Criar um sistema capaz de enviar a mesma mensagem através de diferentes canais de comunicação utilizando o conceito de Interfaces (ou Classes Abstratas).
  - **Comportamento Comum:** O sistema deve ter um método padronizado que receba a mensagem como parâmetro.
  - **Serviços de Disparo (Implementações):**
    - SMS
    - E-mail
    - Redes Sociais
    - WhatsApp

- [ ] **16. Calculadora de Tributos de Produtos**
  - **Objetivo:** Calcular os impostos dos produtos baseando-se em sua categoria. Todos devem possuir um método obrigatório que retorne o valor do imposto.
  - **Categorias e Alíquotas:**
    - **Alimentação:** Imposto de 1%.
    - **Saúde e Bem-estar:** Imposto de 1,5%.
    - **Vestuário:** Imposto de 2,5%.
    - **Cultura:** Imposto de 4%.

- [ ] **17. Cálculo de Área de Formas Geométricas**
  - **Objetivo:** Modelar classes representando figuras geométricas, onde cada uma sabe calcular a própria área utilizando atributos específicos.
  - **Comportamento Comum:** Todas as formas devem possuir um método que calcule e retorne o valor da sua área.
  - **Formas Geométricas Disponíveis:**
    - **Quadrado:** Possui o atributo `lado` *(Área = lado × lado)*.
    - **Retângulo:** Possui os atributos `base` e `altura` *(Área = base × altura)*.
    - **Círculo:** Possui o atributo `raio` *(Área = π × raio²)*.

## 🚀 Como executar os códigos

Certifique-se de ter o [Java JDK](https://www.oracle.com/java/technologies/downloads/) instalado na sua máquina.

1. Clone este repositório:
   ```bash
   git clone https://github.com/GuiStelmach/exercicios
   ```

2. Navegue até a pasta raiz do repositório:
   ```bash
   cd exercicios/Java/5_Interfaces_Lambda
   ```

3. Compile o arquivo Java desejado (exemplo):
   ```bash
   javac Exercicio1.java
   ```

4. Execute o programa compilado:
   ```bash
   java Exercicio1
   ```
