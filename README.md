Bem-vindo ao meu repositório central de **Exercícios de Programação**! 🚀

Este repositório funciona como o meu laboratório de estudos e portfólio pessoal de algoritmos. Aqui, eu documento o meu aprendizado contínuo, aprimoro minha lógica de programação e aplico conceitos de software em diversas linguagens e frameworks diferentes.

## 🗂️ Estrutura do Repositório

Para manter o repositório limpo e organizado, os exercícios estão agrupados em pastas de acordo com a linguagem de programação ou tecnologia utilizada. 

```text
📦 exercicios
┣ 📂 csharp       # Algoritmos, POO e projetos em C# (.NET)
┣ 📂 java         # Exercícios, desafios de lógica e sistemas em Java
┣ 📂 javascript   # Lógica pura, algoritmos e manipulação de arrays/objetos
┣ 📂 python       # Scripts, automação e resolução de problemas em Python
┣ 📂 react        # Componentes isolados e pequenos aplicativos em ReactJS
┣ 📂 typescript   # Exercícios tipados e integração com Node/Front-end
┗ 📜 README.md    # Este arquivo (Visão geral e Índice)
```

> **Dica:** Clique em qualquer uma das pastas acima para ver a lista detalhada de exercícios de cada tecnologia e os enunciados originais.

## 🚀 Como explorar este repositório

Como este é um repositório "poliglota", as formas de executar os códigos mudam dependendo da pasta que você acessar.

1. Faça o clone deste repositório para a sua máquina local:
   ```bash
   git clone https://github.com/GuiStelmach/exercicios.git
   ```

2. Acesse a pasta raiz:
   ```bash
   cd exercicios
   ```

3. Navegue até a pasta da tecnologia que deseja explorar (exemplo: `java`):
   ```bash
   cd java
   ```

4. **Consulte o `README.md` localizado dentro da pasta específica.** Ele conterá o passo a passo exato de como compilar, instalar dependências ou executar o código daquela linguagem (ex: comandos `javac`, `dotnet run`, `npm start`, `python run`, etc.).
